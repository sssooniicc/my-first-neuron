# my-first-neuron

Учебный проект: простейший нейрон (перцептрон) на Python, который обучается логической операции И.

## Что делает программа

Программа получает четыре примера (0 и 0, 0 и 1, 1 и 0, 1 и 1) и правильные ответы к ним. Сначала нейрон ничего не знает и ошибается. После каждой ошибки он немного меняет свои веса и повторяет проходы по примерам, пока не начнёт отвечать верно на всех.

## Как это работает

- `w1` и `w2` — веса входов, `bias` — сдвиг, `speed` — скорость обучения.
- Нейрон считает сумму `w1 * x1 + w2 * x2 + bias` и отвечает 1, если она больше нуля, иначе 0.
- Один проход по всем примерам называется эпохой.
- Если нейрон ошибся, веса меняются в сторону правильного ответа.

## Результат

При скорости обучения 0.1 нейрон выучил правило за 6 эпох.

## Как запустить

`python3 neuron.py`
